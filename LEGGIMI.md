# Pop Daily su iPhone

1. Crea un nuovo repository su GitHub (es. `pop-daily`), pubblico.
2. Carica tutti i file di questa cartella nella radice del repository (Add file → Upload files).
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, cartella `/ (root)` → Save.
4. Dopo 1-2 minuti l'app è su `https://<tuo-utente>.github.io/pop-daily/`.
5. Apri quell'indirizzo in **Safari** sull'iPhone → Condividi → **Aggiungi alla schermata Home**.

Per aggiornare l'app: ricarica il file `index.html` modificato. I dati sul telefono restano.
Backup: scheda Diario → Esporta backup, e salva il file in File o iCloud Drive.
